Rebuilt from CenterContentHeader.tsx at its real metrics, with the embedded Fustat, the hugeicons paths from the installed package and the classroom-light tokens. Every row is the same markup; only the nudge classes change.

the cap-band centre of the 14px title text, measured in the running app at 26.2px below the top of the row. An icon paired with that text should sit on this line.

What is off today

The nudge is right in principle. At 14px Fustat the cap band sits about 1.3px above the flex centre line, so an un-nudged icon really does read low. The problem is that only four of the nine icons get the nudge, and SelectItem does it backwards: it drops the label instead of lifting the icon. Four optical lines in one row.
