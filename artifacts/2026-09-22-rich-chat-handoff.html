State as of 2026-09-22. Working tree on main, uncommitted. Decisions live in human/agentic-retrieval.md (lines dated 2026-09-21 and 2026-09-22); behaviour docs in openwiki/agentic-retrieval.md (chat workflow item 5, "Citations and the frontend").

1. What was decided

TopicDecision
Answer formatOrdinary chat answers are OpenUI Lang programs rendered by @openuidev/react-lang through Capy-owned components. The claims-JSON contract and JSON response mode are gone. Agent tools, SSE transport and chat shell unchanged. Curate mode untouched (prose, PlainRenderer, its own prompt).
PromptOne fixed catalog on every ordinary-chat call; the model picks composition and length.
CatalogMd, Callout, Tabs/Tab, Steps/Step, Accordion/AccordionItem, Reveal, Tags, Facts/Fact, Cards/Card, Table/Row, Chart (bar, hbar, line, area, pie, stacked) + Series, ScatterChart + Point, AskUser. No images, follow-ups, general forms or mutation shortcuts. Tables and charts are leaves; no Tabs in Tabs, no Accordion in Accordion.
CitationsBlocks name shown passage numbers in passages. Python validates (integers only, else repair), orders them in reading order, and the citation list carries each entry's n; the browser numbers markers by list position. Prose gets nearby chips; tables and charts cite beneath, rows individually when needed. Charts are cited or marked illustrative.
Streaming and repairProgressive rendering; one repair call for prose, no root, unknown component, unresolved reference, bad passages or a parse failure; a still-invalid result keeps the valid partial with an interruption notice. Text after a closing fence is dropped. No OpenUI Gateway or Autofix.
QuestionsAskUser blocks for any task (including gathering context before creating materials). Docked block (mock E) between list and composer: one question at a time, numbered choices, "something else" field, Skip, one Send that posts every answered question as an ordinary user message. New turn only: no tool, no held turn state, no question id. Latest completed reply only; skipped questions stay readable as "Asked:" lines; nothing persisted.
LayoutInline reply (mock A): open prose, borders only on tables, charts and interactive blocks.

2. How it works end to end

What the model writes

root = Answer([intro, tabs, cmp, ask])
intro = Md("ACID names four guarantees.", [3])
tabs = Tabs([t1])
t1 = Tab("Atomicity", [a])
a = Callout("info", "All or nothing", "Both updates happen or neither.", [3, 1])
cmp = Table(["Property", "Question"], [r1], [1, 2], "The four guarantees")
r1 = Row(["Atomicity", "Did the whole transfer happen?"], [1])
ask = AskUser("Which guarantee should I go deeper on?", ["Atomicity", "Isolation"])

Passage numbers are the [n] the tool results showed this turn. Optional presentation arguments (unit, illustrative, caption, value) come after passages; the prompt says to write null to skip an earlier optional.

Python (pipeline/pipeline/retrieval/openui.py, agent.py)

  • LangRenderer streams the text through unchanged, minus a wrapping code fence. Prose is held back until the response ends (narration, or an answer that ignored the format).
  • Each completed statement is re-parsed with a small subset parser; the citations event grows in statement order. At the end the list is recomputed in reading order and sent as the final event; Go persists the last list.
  • Validation: root present and an Answer, components known, references reachable from root resolve, passages lists are integers. Failure → one repair call (REPAIR_PROMPT); a valid repair replaces what streamed via a repeated block_start.
  • messages.content is the program. Prior assistant turns replay the program; the checkpoint summarizer gets the text projection (text_of). Evidence retention and search telemetry use the final cited order as before.
  • Prompt: prompts/chat.py appends prompts/openui_lang.txt (about 2,000 tokens; whole system prompt about 2,900). The inline-marker sentence of the old base prompt is gone.

Browser (src/features/workspace/chat/)

  • schema.ts is the single source of the catalog (zod props in positional order, descriptions, groups, prompt options). pnpm gen:openui writes the prompt text and generated/openui_library.json; library.test.ts fails on drift. A file-level biome ignore keeps the formatter from sorting zod keys, which would silently reorder arguments.
  • LangAnswer.tsx renders a program through the Renderer with the chat library; pre-format Markdown answers and rootless program-shaped text fall back to Streamdown; a completed program that stops early or reports parse errors shows the interruption notice. Citation chips look up n in the message's list.
  • Blocks in blocks/: prose via Streamdown, tabs on the shared Tabs strip, native details for accordion and reveal, SVG charts themed by --chart-1..6 (validated for colour-vision separation on both surfaces) with a values table, tables with row attribution, AskUser rendering "Asked:" lines on older replies.
  • QuestionBlock.tsx + questions.ts: questions extracted from the latest completed reply with OpenUI's parser; Send composes "question, answer" pairs into one message through the existing send(). Keys 1–9 pick options; Skip; Hide collapses to a bar; Send respects the composer cap.
  • src/lib/openuiDevtools.ts (first import in main.tsx) disables react-lang's dev-only inspector, which otherwise fetches a bundle from jsDelivr and overlays a deploy prompt.

Go

store.Citation gains N int json:"n,omitempty"; OpenAPI and frontend types regenerated. Nothing else in the gateway changed.

7. Follow-ups outside this change

  • Prompt tuning on GLM 5.3 Flash: the question-style reply tends to land in the model's reasoning channel with empty content; the repair covers it today at the cost of one extra call. You said you would tune the prompt; the catalog text and rules live in schema.ts (promptOptions) and the base rules in prompts/chat.py.
  • The lab index container on the ingest host has no restart policy, so it stays down after a host restart until started by hand.
  • Marker numbering during streaming follows statement order until the final list arrives; a model that writes children out of order shows a one-time renumber.
  • The lab/playground scripts still carry their own copy of the old claims helpers (citations.py "structured" mode); the playground itself runs the current agent, so only that optional mode is stale.
  • The enum-argument list used by the text projection (Callout.kind, Chart.kind) is hand-maintained; the generated spec carries names, not types.
