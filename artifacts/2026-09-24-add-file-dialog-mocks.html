Create, round 2

Same sidebar and scroll-tracked gallery as Choose icon. Changes from round 1:

  • Tiles are ButtonCard, set up like the Generate panel: outline card, lifts on hover, 22 px Catppuccin icon, medium 14 px label.
  • Grid fills columns at 140 px or wider, 3 per row at this width. The Generate panel uses 160 px, which only fits 2 here.
  • Selected tile gets an accent border and tint, with no check badge. ButtonCard has no selected style today, so it would read aria-pressed.

Still open from round 1

  • Chapter on create. Upload rows have a chapter picker. Should Create ask for a chapter too, or put the new file under No chapter?
  • Click behavior. The mock selects a tile first, then Create. Should one click create it right away instead?
  • Section name. Presentations (matches Documents and Spreadsheets) or Powerpoint?
  • The real dialog has no drop handling yet. Clicking the box opens the file picker, but dropping a file does nothing. The build would add drop handling on the Upload tab.
  • The sidebar and gallery come out of IconPicker into one shared component. IconPicker keeps its icon grid, and Create passes the ButtonCard grid.
