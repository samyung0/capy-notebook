Responsive proposal

Hide the sidebar and divider below 768 px. Keep all five named sections in the same gallery. Show six columns on tablets, four on phones, and three below 360 px.

Preview widths are capped to fit this page. Each dialog also responds when you resize the browser.

Dialog behavior

Only the gallery scrolls. The title and Cancel / Use icon stay visible. Phone buttons sit side by side, with the same 52 px height as desktop.

The app dialog will fit within 88% of screen height, shortening the gallery on short screens. Opening starts at the selected icon's style.

Artwork from the existing catalog: Sprouts, Critters and Waves by DiceBear; Avataaars by Pablo Stanley; Notionists by Zoish. Preview only; app code is unchanged.
