Editor comment popover

The popover that opens from the comment count on the right of a block. Resolve is gone from every option; threads are only deleted. All three options use the All blocks menu's shell: 8px radius, 1px border, the pop shadow, 4px side padding with 8px row insets, 28px menu rows and 12px muted labels. No "Add:" or "Delete:" suggestion lines. Sending a reply uses the arrow-right icon. Light theme only.

Applies to every option

  • Width 360px (today 380px), capped at the viewport minus 24px. Placement stays on the left of the trigger.
  • The "Comments" header bar and its close button go away. Esc or clicking outside closes it, like the other editor popovers.
  • Each comment: avatar, name, time, text. authorAvatarUrl fills the avatar, otherwise initials on the accent tint (the existing Avatar component). Edited comments get a muted "(edited)".
  • Time: minutes or hours under a day ("10m", "4h"), otherwise a short date ("2 Sep"), with the year only when it isn't this year.
  • Per-comment actions move into a ⋮ menu that shows on hover: Edit (own comment only), Delete (own comment, or any comment for the workspace owner). No ⋮ when neither applies. The inline Reply / Edit / Delete buttons go away.
  • The send button stays greyed until the field has text, then fills with the accent colour. Enter sends, Shift+Enter adds a line.
  • Viewers (no edit access) see the threads with no reply row and no menus.

AFlat list, closest to the Plate reference

  • Threads stacked with a full-width divider between them. The quoted text sits under the first author's name with an accent bar.
  • Hovering a comment shows ⋮. On the first comment the menu has Edit and Delete thread.
