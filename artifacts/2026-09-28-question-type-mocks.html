Question type styles: current app against the chosen direction

Round 3 applies your picks: letter keys (B) everywhere, true/false buttons while answering, and B′ phone spacing. Each type shows the current app (A) beside the chosen style, before and after checking, with the app's classroom tokens in light and dark. Questions are real pilot items.

Theme
Width
Matching view Multiple choice, one answer Multiple choice, several answers True or false Short answer with a unit Open answer Matching (quiz) Ordering
  • Choice letters sit in a 26px rounded-square key (8px radius). Ordering numbers and matching letters use the same 26px column without a border, so every label shares one left edge.
  • Selected, correct, wrong and half-mark rows copy the editor callouts: tint background, rounded-lg, 1px border in the solid colour at 45% opacity. Selected uses the tip colours.
  • Answer rows span the text column and the marks column, so the marks line up above the right edge of the rows.
  • Formulas are plain text here; the app renders them with MathLive.
