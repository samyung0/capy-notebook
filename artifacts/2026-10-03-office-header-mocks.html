Office file header and toolbars

Mock for approval, 2026-10-03. DOCX, XLSX and PPTX get a two-row file header in view and edit mode, and in edit mode one toolbar row under it ordered after Google Docs, Sheets and Slides. Notes, PDFs and other files keep today's header. Frames are built from the app's own CSS, Fustat and Hugeicons, captured from the MSW dev server at origin/main c0fa4634; the Office canvases (page, grid, slides) are drawn stand-ins.

  • Header: back, sidebar toggle, workspace, file name and save status on the top row; File, Edit, View, Insert… from the left edge on the bottom row; Save, the mode toggle and ⋮ on the right.
  • View mode shows only the menus that apply (File, View). Edit mode adds the format's menus and the toolbar row. The editors' ☰ buttons are gone.
  • No AI items: XLSX ✦ proposals and PPTX Agent proposals are hidden.
  • Below lg, DOCX hides font, size and zoom; XLSX hides font, size and zoom. The toolbar row scrolls sideways on narrow screens.

Header

Grid of two columns and two rows inside today's 56px (h-14, 1px divider). Top row: back, sidebar toggle (lg+), workspace pill (lg+), file icon, file name (t-body semibold), save status in edit mode. Bottom row: menu triggers from the header's left edge, the first label's text aligned with the back icon. Right column: Present (PPTX, variant 5A), Save (edit), mode toggle, ⋮. ⋮ keeps today's file actions (Full screen, Rename, Move file, Properties, Delete). The “not indexed” banner and other FileBanner strips stay between the header and the toolbar row; they are left out of the frames. Menus open with Capy's DropdownMenu (rounded-card, shadow-pop, 224px minimum), shortcut text right-aligned in text-fg-muted. Below lg the top row loses the sidebar toggle and the workspace pill, as today. Below sm the right controls sit on the top row whatever variant 4 says, so the menu bar gets the full width; it scrolls sideways if it still does not fit (PPTX's seven menus at 390). At 1280 beside the chat column the DOCX and XLSX rows are wider than the panel (DOCX lists and Clear formatting, XLSX alignment); they scroll, as today's rows do.

Commands I would drop (Epo's call)

  • DOCX Insert › Table of contents: a no-op today. Leave it out until it inserts something.
  • DOCX table ⋮ items that do nothing: vertical alignment, table alignment, header row, distribute columns, auto-fit, no-wrap.
  • DOCX Line spacing's empty “Paragraph spacing” heading.
  • DOCX Superscript and Subscript: they move to Format › Text, but they do nothing today. Either fix the toolbar bridge (the engine's toggle_mark supports them) or drop them.
  • XLSX “Custom number format…”: there is no dialog, it reapplies the current pattern.
  • PPTX toolbar Save icon: duplicates the header's Save and File › Save.
  • PPTX font size −/+ steps and the ⋯ overflow menu: replaced by the size box and sideways scrolling, as in DOCX and XLSX.

Found while mapping

  • The runtime iframe is sandboxed with allow-same-origin allow-scripts only. That should block window.print() (XLSX Print), anchor downloads (XLSX/PPTX PNG export) and popups (DOCX print window, link Open). Not verified in a browser.
  • DOCX keyboard ⌘C/⌘X appear to copy nothing (no copy/cut listener on the hidden textarea); right-click Copy works. Worth a manual check.
  • PPTX Agent proposals has no hide prop; it shows whenever the WASM build has proposals. Hiding it needs a showProposals prop like XLSX's.
  • DOCX Page setup and Watermark change the legacy document, not the Yrs session, so collaborators may not receive them. Not verified.

Open questions (recommended option first)

  1. Rows: A (4 + 28 + 22) or B (0 + 32 + 22).
  2. Menu label size: A 14px, matching the toolbar, or B 13px.
  3. Save status: A icon after the name, as today; B icon and word; C at the end of the menu bar.
  4. Right controls: A centred on both rows, or B on the top row.
  5. Present: A in the header in both modes, or B at the end of the edit toolbar with View › Present in view mode.
  6. Download: add File › Download in both modes as a host action (signed link, as FileViewer), not in ⋮; or also in ⋮.
  7. Rename, Move, Properties, Delete: stay in ⋮ only, or also under File as Google has them.
  8. DOCX Find and replace: enable the fork's dialog in edit mode (Edit menu, ⌘F/⌘H), or keep it off. Its Replace has no read-only guard, so edit mode only.
  9. Engine-only commands with new menu items (XLSX rows, columns, freeze, add sheet, clear formatting; PPTX delete and move slide, delete shape; DOCX ruler): include them in this round, or ship the header with today's commands only and add them after.
  10. Print, PNG and download from the iframe: route them through the host by message, or relax the sandbox (allow-modals, allow-downloads, allow-popups).
  11. View-mode items that need wiring (DOCX Print and Zoom, XLSX Zoom, PPTX PNG and Present): add each when it works and never show disabled items, or ship view mode with File › Download only.
