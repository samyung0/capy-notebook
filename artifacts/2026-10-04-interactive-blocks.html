Interactive blocks in notes

Phase 3 of the learning plan: a note block holding a small HTML interactive the agent writes (an html-embed fence). It runs in a sandboxed frame with no network and no access to the app, sizes itself to its content, and follows the light and dark theme through colour variables. Every interactive carries a plain-text fallback for export and for viewers where scripts cannot run. The agent writes it; learners do not edit the source (the source view is read-only). The images are real note styling from the app with the block mocked in; the interactive here is drawn statically.

To pick: (1) A, B or C for the block; (2) whether the source view is wanted at all, or only Copy.

A · media frame, like diagrams

Same frame and hover toolbar as mermaid diagrams and charts; the toolbar has View source, Copy and Delete. The title shows as the caption.

B · labelled card

A bordered card with an Interactive label and title in a header row; actions in the ⋮ menu. Reads as a different kind of block from figures.

C · frameless with a label

Like A without the caption; a small Interactive label marks that it moves.

Fallback

What an export (DOCX, PDF) or a viewer without scripts shows: the fallback text the agent wrote, labelled.

Source view

Opened from View source; read-only with Copy. Changes go through chat.
