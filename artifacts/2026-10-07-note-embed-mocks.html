Quizzes and flashcards inside notes

The embed block renders the real study and edit components inside the note: one React component per Plate block, no iframe and no second renderer. Everything below is captured app markup with the app's CSS, in the note's column (dark theme). Grey italic lines are mock notes, not UI.

  • View (note View mode and the public note page): the quiz takes answers and Submit grades it in place; flashcards flip and the rating tiles move to the next card. Embedded items are quick checks, so nothing is recorded (2026-10-06).
  • Edit (note Edit mode): the quiz editor's Edit and Remove per question and the flashcards grid with its hover toolbar replace today's single Edit button.
