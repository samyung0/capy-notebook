Mermaid materials without Plate

Standalone mindmaps and diagrams. Edit shows source and preview side by side, saving every change to the existing room. Every frame below is built from the app's real shell and CSS, with the real rendered diagrams.

App theme

1. Edit on desktop

All three show the same moment: line 5 is missing its closing ]. The line gets a red number and wavy underline, and the preview keeps the last diagram that worked. The message is the same everywhere: "Syntax error on line N". No Save button; each change saves as you type.

A

Controls bar on top

A flat bar above both columns: theme dropdown on the left, the error on the right. The caption is typed under the preview, like in notes.

B

Controls with the preview

No bar. The theme dropdown sits at the top of the preview column, since the theme only changes the preview. The error is a strip at the bottom of the code column.

C

Error above the preview

No bar and no theme control in the body. The theme moves to the ⋮ menu in the header. The error sits above the preview and says the preview is out of date.

2. Edit on phones

One column. The Preview button sits beside the theme dropdown. If a syntax error shows, it goes in the same place as the desktop pick.

P1

Preview swaps the column

Tapping Preview replaces the code with the diagram and the button becomes Code. The caption is edited on the preview side.

P2

Preview opens full screen

Preview opens the existing full-screen view, the same one used when you tap a diagram in a note. Close it to keep typing. The caption field would need another place, such as under the code.

3. Errors in View

The broken diagram seed today prints mermaid's raw parser dump ("Parse error on line 3: ... Expecting 'SQE', 'DOUBLECIRCLEEND' ...") above the source. Both options replace that with the same line-number message the editor uses. The same message would show in note blocks and on shared pages.

V1

Message and source

The message, then the source with the line marked, like the editor.

V2

Message only

No source. A short notice, and an Edit source button for people who can edit; viewers see only the message.
