Live item editors: no Save, no Done

Reference for the live-items UI work (Epo, 2026-10-10). Quizzes, flashcard sets and Mermaid diagrams save every change as you type. Save, Cancel and Reset are gone and there is no Done: dialogs close with their close button or Esc; the quiz and flashcards edit pages and the standalone Mermaid editor leave editing through the View/Edit switch, as notes do, with the cloud status after the title and Undo/Redo buttons. Every frame uses the app's compiled CSS and tokens.

App theme

0. The live state

The status uses the icons the note header uses. Undo and Redo undo only your own edits (others' typing stays). Offline edits stay on this device and sync on reconnect (2026-10-04).

1. Question dialog

Fields edit the quiz directly. The footer holds Undo, Redo and the status at its left and Remove part at its right; the dialog closes with X or Esc. The outline row of an unfinished part carries the warning icon and the preview says what is missing (D4). Editing a block opens inside the dialog as today, with a back arrow instead of its own Save.

2. Card dialog

Front, image and back edit the set as you type; the image uploads as soon as it is picked (D6). Shown offline: the status says the edits are kept on this device.

3. Note Mermaid dialog

Option D's layout (source left, live preview right); Cancel and Save give way to the footer status. CodeMirror's own Undo (Ctrl+Z) undoes your typing; the footer buttons do the same.

4. Standalone Mermaid editor

Option A of 2026-10-09 without Cancel and Save: the cloud status after the title, the View switch to leave editing, Undo and Redo at the bar's right.

5. Quiz edit page

The questions render as learners see them, each with Edit and Remove. The cloud status follows the title; Undo, Redo and the View switch sit at the header's right. An incomplete question shows a line under it saying what is missing: learners see it as it is typed, but it is not marked until it is complete (D4). The General tab's name saves on blur.

6. Flashcards edit page

The card grid with its hover toolbar and the dashed Add card tile; a card edit or removal applies at once. Same header as the quiz page.
