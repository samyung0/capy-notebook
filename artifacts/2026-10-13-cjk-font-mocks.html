CJK font stack options

The page sets <html lang="en"> like the English UI, so the browser picks CJK fallback per character as it does in the app. Every sample uses the app's stack for the chosen style with the variant's CJK families inserted after the Latin fonts (before system-ui in classroom, before sans-serif in notion). Fustat is embedded (Latin subset only, as in the app), so Latin and digits render in Fustat in the classroom style.

Why B, C and D look heavier

Today's fallback font (Hiragino Kaku Gothic ProN) has only two weights, W3 and W6, and Chrome draws 500 with W3, so CJK text has been lighter than the 500 the app asks for (and 查 lands on W6, the heavy one). Which font draws each character

Each character is drawn on a canvas with the variant stack (lang="en", same as the app) and compared pixel for pixel against each installed CJK font on its own. A row turns red when its characters come from more than one font. Fonts that draw a character identically are listed together (PingFang SC/TC/HK share most glyphs). A font name with a weight (for example Hiragino Sans 600) means the fallback drew a heavier or lighter face than the text asked for. Fonts not installed on this machine are skipped, so the Windows and Linux names (Microsoft YaHei/JhengHei, Noto) only show on those systems.
