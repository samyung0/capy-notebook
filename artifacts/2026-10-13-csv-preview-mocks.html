Notes for picking

  • Sort is client-side over the 500 preview rows only; when the file is truncated the existing note under the table already says so. Numbers sort numerically, empty cells always go last, text uses localeCompare with numeric collation.
  • The header row is assumed to be the first CSV row, as today. A sort never moves it.
  • The column cap stays at 50; the sensor log here is 32 wide. Truncated values keep their full text in the hover title.
  • Recommendation: A + W2 + P1. Always-visible chevrons work on touch, and W2 is the cheapest layout for the 500-row preview.
