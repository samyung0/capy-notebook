Selecting files, blocks and trash items

Today Select replaces Sort and Filter with a count, Select all and Restore, and adds Delete or Delete forever and Cancel on the right, so the toolbar reflows (and on phones wraps into a new layout). Each option below keeps the toolbar still. Drawn on Files with the phone toolbar from today (icon-only sort and filter); Blocks behaves like Files.

Pick A, B or C (or a mix, e.g. C on desktop with A on phones).

A. Floating action bar

Select (top right, same place as today) turns on check boxes; its label becomes Done. The toolbar never changes, so nothing reflows. Count, Select all and the actions live in a floating pill at the bottom of the panel, the same shape as the question bank's floating bar. Trash keeps Empty trash in the toolbar; Restore and Delete forever move into the pill.

B. Contextual header

Select swaps the toolbar for one tinted row of the same height: ✕, the count, Select all, then the actions on the right (icons only on phones). Leaving selection swaps it back. On phones the two toolbar rows become one, so the grid moves up by one row while selecting.

C. No select mode

No Select button. On desktop a circle shows on the hovered card's thumbnail; clicking it selects without opening the file. On phones a long-press selects (and the ⋯ menu gets a Select item). Once one card is selected every card shows its circle, tapping a card toggles it, and A's floating bar appears; ✕ in the bar ends selection. Without a Select button the phone toolbar fits on one row.
