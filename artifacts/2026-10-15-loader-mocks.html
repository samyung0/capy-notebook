Loaders: current vs ldrs ring, squircle, bouncy, leapfrog

Every place the app shows Spinner today (plus the editor's two animate-spin loaders), drawn at its real size and colour, with each ldrs loader dropped into the same slot. The code is ldrs 1.1.9's CSS, ported as-is; only the stroke is set to today's weight (2 of 24) so ring and squircle read at the same thickness.

  • Bouncy and leapfrog are wider than tall (0.6 ratio), so in an 18px square slot they shrink to 3–4px dots. The Dot loader width control widens them. Defaults are now your pick: same as slot, 30% slower.
  • ldrs default speeds are ring 2s, squircle 0.9s, bouncy 1.75s, leapfrog 2.5s (3.25s at 30% slower). Today's spinner turns once a second.
  • All four stay small: ring and squircle are one SVG with two shapes; bouncy and leapfrog are three elements with pseudo-element dots. They're CSS only and use the theme colour through currentColor.
