Study page in the workspace, under 1260px

Study lost its tab below 1260px with the R3 layout. These are three takes on a Study page opened from the header ⋮ (Open study), with the chat page's header: back, title, ⋮. Frames are drawn on real screenshots (MSW, Biology 101); phones at 80%, the 820px iPad at 55%. Everything the Study tab shows today is on each page: Continue, Review, Quick review cards, Done per chapter, Recent quizzes and the Track progress switch.

Pick A, B or C. Parts mix, e.g. B with A's switch at the bottom. Then answer the open questions at the end.

Opening and leaving (same for every option)

Open study is the first item in the file ⋮. The Study page covers the file the way the chat page does, and Back returns to the file with its scroll kept. No chat button on the Study page. From 1260px up nothing changes: Study stays a tab in the side panel.

A · The panel, as a page

Today's Study tab moved onto a page as it is: same order, same sizes, the Track progress switch at the bottom. The header ⋮ holds Add file and Workspace settings, like the chat page. The least new code: StudyPanel renders inside the page.

B · Practice first

Opening Study is mostly for practising, so the Quick review card leads, full width and larger. Continue and Review follow under Up next. Chapter rows get a ⋮ (Continue here, Review this chapter, both existing routes). Track progress moves into the header ⋮ as a switch row. Once the last card is rated the card section leaves (as today) and Up next is on top.

C · Progress up top, chapters open into files

A progress line across the top (done of tracked, the workspace's trail stretched to the page), then Up next. Quick review folds into one row with a bordered Start, so the page stays short; Start opens the cards in place. Chapters open into their files with a check on the read ones and a ⋮ per file (Open, Mark as read, Stop tracking, the same as the file ⋮). Track progress sits in the header ⋮ as in B. New: the per-file list and the progress line; the label Done becomes Chapters.
