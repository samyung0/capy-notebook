Workspace page on phones: R3

Real app screenshots with the changes drawn on top, phones at 80%, iPads at 42%. Frames with a Replay button are live.

Header and menus

Phones: back, file icon, name ▾, pen/eye, ⋮. The book (mark as read) and the offline, workspace and save status icons are hidden on phones; ⋮ gains Add file (the circular add), Mark as read and Workspace settings. Study gets its own page later; until then it has no entry below 1260px. Files drops from the top: workspace name as a plain row, list scrolls past a max height, Workspace settings pinned.

Chat on phones

Every file gets the round chat button (52px, up from 44). Tapping it grows it into the field (one line, send on the right) and focuses it. The field grows only when the text needs another line. Blurred and empty, it folds back into the button; blurred with text, it stays open. Scrolling with text in it fades the field down and out and brings the button back. Send grows the field into the chat page; the keyboard closes there so the answer gets the page.

Office files on phones

xlsx and pptx: the same button sits above the sheet tabs or slide pager, and opens the same field. Typing on a note and on a spreadsheet looks the same: one line, 8px above the keyboard.

Citations

A citation opens the file at the cited part. A chip with the conversation name sits beside the button: tap it to go back, or ✕ to close it and stay on the file.

Notes

  • The dot on the button after a scroll means a draft is kept. My addition; drop it if you don't want it.
  • Mark as read uses the closed book with a check, which the header already shows once an item is read.
  • The chat page title has no ▾, so Files is one Back away.
  • Keyboard: index.html has the plain viewport tag and nothing reacts to the keyboard. Add interactive-widget=resizes-content for Chrome Android, and size the page to visualViewport.height for iOS Safari, which pans the whole page otherwise.
  • Code: Files uses the existing Drawer with swipeDirection up; the floating bar, the rail tabs drawer and the Office tools menu go away below 1260px; the Office button becomes the chat button and is reused on every file on phones.
