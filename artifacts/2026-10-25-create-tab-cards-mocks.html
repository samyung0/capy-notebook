How the thumbnails are made
  • Study materials and CSV: a TEMPLATE_PREVIEWS constant holds a preview object per kind, in the same shape the server stores for materials (note blocks, a quiz's first question, a card front, a diagram's Mermaid source, CSV text). ThumbnailPanel draws them with the code it already runs for Recent Files. That means no image files, both themes, and sharp at any size. Text goes through paraglide so the zh cards are in Chinese.
  • DOCX, XLSX and PPTX blanks: three small drawn pages (page, grid, slide), dimmed in dark mode the way real page images are.
  • PNGs only when a template has real content, for example a future "Lab report" DOCX. Then the ingest host's page-1 render makes the image once, it's committed as a small WebP under public/templates/, and the card passes it as thumbnailUrl like any uploaded file.
