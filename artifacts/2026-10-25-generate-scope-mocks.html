AI generate scope picker

Today the tab has two pill lists, Chapter scope and File scope. They look like the option pills below them, files aren't grouped by chapter, and "whole workspace" is only a grey line that disappears once you pick something. Each option below replaces both lists with one tick list over the same Biology 101 sources, where ticking a chapter ticks its items.

Same in every option
  • One Sources list: Whole workspace, then each chapter, then Others. Ticking a chapter ticks everything in it. A chapter with only some items ticked shows a dash.
  • Whole workspace is ticked when the dialog opens. If you untick everything, Generate turns off, so an empty pick never quietly means "everything".
  • Notes and cheatsheets appear next to uploaded files. The server already accepts them in scope, but today only uploaded files can be picked. Files that are still processing stay hidden, as they are now.
  • The other options use label-left / control-right rows with dropdowns instead of pill rows: Amount (5 or 10), Question types (a tick menu), Detail, and Diagram type.
  • The grey line under each desktop frame shows the request the current pick would send. A fully ticked chapter goes in chapters and leftover items go in fileIds, which is the union the server already computes.

A · Chapter tree in the form

The list sits in the form, with chapters collapsed. Use the chevron to open a chapter and pick single items inside it. It's short when you don't need it and complete when you do, and it scrolls inside its own band so the options stay close to the top.

B · Sources dropdown

Sources becomes one row, like Amount, and shows a summary such as "Whole workspace" or "Genetics, Membranes & transport, 1 more". The tick list opens in a popover. Single items are behind a "Single items" link, as in the Study plan's Add steps. This is the shortest form, but you have to open the popover to see what's picked.

C · Study plan's tick list, inline

This reuses the rows from AddStepsPopover directly in the form: a flat chapter list, with all single items listed together under a "Single items" link. It needs the least new code, but single items lose their chapter grouping.
