These boards turn it round: Settings first, Questions second, and one Create that sends everything.

Board 2 · Questions, then one Create

From a quiz: copy one the workspace already has

  • Lists the workspace's practice quizzes and earlier graded quizzes, newest edit first. One pick (a radio): the graded quiz gets a copy of every question, images included, as From the bank copies today. Editing the copy never changes the original.
  • Create sends the settings and the questions in one request; the server makes the quiz and the graded quiz in one transaction. No quiz exists before Create, so Cancel leaves nothing behind.
  • Tabs keep today's order with From a quiz before Create blank, which stays last.

Board 3 · Questions that take a while

Generate and Convert still send one request

Their questions come from a run that takes minutes, so one request can't hand them back at once. Create sends the settings plus the run's inputs. The server saves the graded quiz as a draft and starts the run, and the run's quiz goes straight into that draft. Today the quiz is made first and swept to the trash after a day if no graded quiz takes it; that sweep goes away.

The button says Create draft, so nothing reaches members before a teacher has read AI-made questions. Create blank also saves a draft and opens the empty quiz to write in.

How others do it

All three set the quiz up first and add questions after

  • Canvas (New Quizzes): the Details tab holds title and points, and Assign Access holds assignees, due and availability dates; questions are added on the Build page after the quiz is created. To reuse a quiz, the quiz's options copy it (Copy To / Send To), and instructors duplicate it first so the questions come along. Canvas New Quizzes has no separate practice type; a practice quiz is an ordinary quiz set not to count toward the grade.
  • Google Classroom + Forms: Create › Quiz assignment takes title, instructions, assignees and due date; Classroom makes a blank Forms quiz and attaches it, and the questions are written in Forms. An existing form can only be attached as a link, which loses grade import.
  • Moodle: adding a Quiz activity opens its settings form (name, timing, grade); Save and display, then Edit quiz adds questions, including "+ from question bank". A whole quiz is reused with the activity's Duplicate.
