## Remaining work, ranked by user impact

1. **Pagination like Word: page count, keep with next, widow and orphan control, rows split across pages, repeated header rows** (docx.view.pagination; P0, impact 5, effort M; view P). Run the fork's Benchmarks workflow (scripts/office-quality, DOCX channel) on capy-ci, keep page agreement and SSIM per pin in this report, and fix the worst documents first.
2. **Copy, cut and paste** (docx.edit.clipboard; P0, impact 5, effort M; edit P). Rich paste: read text/html (Word, Google Docs, browsers) and map runs, paragraphs, lists, tables and pictures onto engine ops; write HTML on copy too.
3. **Equations (OMML)** (docx.view.equations; P0, impact 5, effort L; view P, edit N). Lay out OMML in 2-D in docx-layout (fractions, scripts, radicals, delimiters, n-ary operators, matrices) with the math font's tables; an equation editor is a later, larger step.
4. **Edited documents save as Word writes them, losing nothing beyond the edit** (docx.save.edited; P0, impact 4, effort M; save P). Fix the two losses; open a set of Capy-saved files in Word (manual, Epo's machine) and record the result.
5. **Numbered and bulleted lists, multilevel numbering, restarts** (docx.view.lists; P0, impact 3, effort S; view P). Check start values, legal and Chinese numbering on Word-made files and fix what differs.
6. **Headers and footers: first, even and odd pages, page numbers** (docx.view.headers; P0, impact 3, effort S; view P). Shrink the tab by the resolved minus the cached field width on each page (docx-layout display_list.rs).
7. **Alignment, indents (menu and ruler), line spacing, tab stops, space before and after** (docx.edit.paragraph; P0, impact 3, effort S; edit P). Add space before and after to Line spacing, as Google Docs' Line & paragraph spacing does.
8. **Typing, selection, keyboard navigation, IME composition** (docx.edit.typing; P0, impact 3, effort M; edit P). Line-aware Home and End, with a caret affinity at wrap points.
9. **Bold, italic, underline, strikethrough, superscript, subscript** (docx.edit.character; P0, impact 3, effort M; save P, collab U). Save only the run properties the editor changed, as the paragraph save already does.

11. **Tables: insert, rows and columns, merge and split, borders, cell fill, alignment, header rows, distribute, auto-fit, wrap, column drag** (docx.edit.tables; P0, impact 2, effort M; collab P). Make concurrent row changes merge per row instead of per table; fix the edit/view font and width differences.
12. **Word count** (docx.edit.word_count; P1, impact 4, effort S; edit N). Tools › Word count (words, characters, pages; for the selection and the document), as Google Docs.
13. **Table of contents: insert and update** (docx.edit.toc; P1, impact 4, effort M; edit P). Read TOC fields and headings inside block content controls and table cells.
14. **See where co-editors are (live cursors and selections)** (docx.collab.presence; P1, impact 4, effort M; collab N). Relay awareness between the host provider and the runtime frame for DOCX, XLSX and PPTX, with names and colours as in notes.
